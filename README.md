# Имитация рулевого управления автомобиля на STM32

STM32 только читает джойстик (ADC1+DMA) и крутит серво (TIM3_CH1, PA6). Вся математика руля и кинематика - в Python.

**Платформа**: STM32F103RB (Nucleo), среда CubeMX и CubeIDE. **ПК**: Linux Fedora 43


### Требования:
- Джойстик имитирует рулевое колесо. От центра до упора около 1.5 оборота (±540°), от упора до упора 3 оборота.
- Центральное положение равно 0°. На упоре вращение дальше в ту же сторону угол не меняет. Вернуться можно только вращением в противоположную сторону.
- Передаточное число рулевого механизма (Steering ratio) = 17:1, означает, что 17° поворота рулевого колеса это 1° поворота управляемого колеса. При ±540° получается δ ≈ ±31.58°. Эталон: Mitsubishi Galant ES.
- Для угла руля используется только круговое (угловое) положение стика. Величина отклонения от центра и другие оси в расчёт угла руля не входят.
